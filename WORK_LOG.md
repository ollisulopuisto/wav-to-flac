# PR 3 review follow-up, 2026-11-17

The pipeline loop and its final partial-batch wait now run in the same worker-owning shell. Every PID's status is collected. Failure is reported only after all other workers finish, and no success footer is printed on failure. Batches intentionally retain Bash 3.2 support; this is not a work-stealing pool. Functions are not exported. Default concurrency is capped at two workers (one on a single-CPU host), an explicit `-j 1..8` sets the bound, and each encoder uses one thread.

Each conversion writes to a unique same-directory temporary file. Before any original can be moved, verification checks the FLAC signature, strict decoded PCM hashes, sample rates and channel counts. Verification therefore rejects a truncated existing file and a valid but different file, rather than trusting size alone. Successful real conversions are renamed into place without overwriting another output. Dry runs never publish a new final file. Failed/interrupted unpublished files are removed by the worker's cleanup trap. SIGKILL and power loss cannot run cleanup, but their `.tmp.*` files are not accepted as final output. Recycle-name collisions are refused, and recycle directories are excluded from discovery. Each worker's log lines carry its input path.

Validation: 13 Python unittest cases pass using generated WAV/AIFF audio, real ffmpeg/ffprobe, and temporary recycle directories. The completion case exercises 1, 2 (exact limit), and 3 (limit plus 1) files, observing cleanup before the success footer. Other cases cover non-last worker failure, failed partial output, truncated and wrong existing FLACs, non-FLAC content, timestamps, stereo AIFF/title preservation, SIGTERM cleanup, dry runs, job bounds, and recycle collisions. Against the original head, completion, truncated-file safety and failed-encoder status cases fail. Shell syntax, ShellCheck and git diff whitespace checks pass locally.

CI is added for Linux and macOS without artifact or cache uploads. macOS Bash 3.2 and a real Synology NAS were not tested locally. No real music library or existing recycle bin was touched. The original speedup claim is withdrawn: strict verification adds decoding work, and no new wall-clock benchmark was run. Exact-head CI and a fresh clean Devin review remain merge gates.
